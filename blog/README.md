# Tom Siwik site

TanStack Start SPA for tomhacks.com with Fumadocs MDX collections, Tailwind CSS, and the Hatch visual theme.

```bash
pnpm install
pnpm dev
```

Content lives in:

- `content/blog` for posts
- `content/work` for portfolio projects
- `content/services` for service pages

Run the local gates with:

```bash
pnpm types:check
pnpm lint
pnpm build
pnpm start
```

`pnpm build` prerenders the site for the `/tomsiwik/` GitHub Pages base path and prepares `.output/public` with `index.html`, `404.html`, and `.nojekyll`.

The shadcn-compatible proof-of-concept registry lives in `registry.json`. It currently publishes the `profile-avatar` component and `author-card` block:

```bash
pnpm registry:build
```

Generated install artifacts are written to `public/r` and are regenerated by `pnpm build`.
