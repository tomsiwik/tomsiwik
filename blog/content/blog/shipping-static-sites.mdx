Static output is a deployment property, not a restriction on how carefully an application can be designed. Routes can be typed, content can be structured, and selected components can hydrate in the browser.

## Separate the layers

The build has three distinct jobs:

1. Compile and validate content.
2. Render every public route to an artifact.
3. Hydrate only the interactions that need client state.

```text
MDX content -> typed source -> route renderer -> static HTML
                                      |
                                      +-> optional client chunks
```

## Verify the artifact

Serve the output directory, not the development server. Then probe deep links, asset paths, feed content types, and the fallback page under the same base path used in production.

This catches the class of problems that only appears once a site leaves the root of a domain.
