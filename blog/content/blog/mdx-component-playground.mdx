## Code blocks

The highlighted block below should scroll horizontally on narrow screens without widening the page.

```tsx title="counter.tsx"
type CounterProps = {
  initialValue?: number;
};

export function Counter({ initialValue = 0 }: CounterProps) {
  const [count, setCount] = useState(initialValue);

  return (
    <button type="button" onClick={() => setCount((value) => value + 1)}>
      Count: {count}
    </button>
  );
}
```

Inline code such as `pnpm build` should remain readable inside a sentence.
